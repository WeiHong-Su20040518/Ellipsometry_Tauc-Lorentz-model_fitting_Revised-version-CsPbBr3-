# Ellipsometry_Tauc-Lorentz-model_fitting_Revised-version-CsPbBr3-
It can be used to fit the n,k of CsPbBr3 quantum dots(Multi-oscillator fitting system)

需在終端機執行:
pip install streamlit numpy pandas plotly scipy
streamlit run Ellipsometry_fitting_CsPbBr3.py

*Ellipsometry_fitting_CsPbBr3.py為檔案黨名，若你自己把檔名叫做123.py，那就執行:
pip install streamlit numpy pandas plotly scipy
streamlit run 123.py
